一句话定位
AI-Studio 是面向企业多租户场景的 AI 应用平台，把多模型接入、RAG 知识库、可配置 Agent、插件工具、可视化工作流与权限审计统一到一套前后端系统中。

30 秒项目介绍

我做的是一个 React + FastAPI 的企业级 AI 应用平台。它不是单纯封装大模型接口，而是把模型、Prompt、知识库、Agent、插件和工作流统一治理。后端用 SQLAlchemy + MySQL 管业务数据，Qdrant 做向量检索，Redis + Celery 做限流和异步文档处理；前端用 React Flow 做工作流、SSE 做对话与执行过程流式展示。项目里我最关注的是多租户隔离、端点级工具授权、RAG 可追溯引用，以及外部依赖失败时的降级与可观测性。
